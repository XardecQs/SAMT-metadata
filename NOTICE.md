# Aviso de autoría — carátulas y capturas

Este repositorio contiene, además de los manifiestos `mod.toml`, **carátulas**
(`cover.*`) y **capturas** (`screenshots/**`) de cada mod.

Aunque los `mod.toml` y la documentación de este repositorio están bajo CC0 1.0
(ver [`LICENSE`](LICENSE)), **las imágenes no lo están**. Las carátulas y
capturas son obra de los autores de cada mod —o de sus respectivas webs de
publicación— y se incluyen aquí **únicamente con fines de identificación**, para
que el organizador pueda mostrar una ficha visual de cada mod.

Todos los derechos pertenecen a sus autores. Si eres autor de alguno de estos
mods y quieres que se retire su carátula o capturas de este repositorio, abre un
issue y se eliminarán.

Las capturas propias (hechas por quien mantiene este repo) se rigen por la
licencia CC0 del repositorio salvo que se indique lo contrario.
